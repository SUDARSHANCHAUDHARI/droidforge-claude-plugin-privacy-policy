Privacy Policy

Last updated: April 6, 2026

This Privacy Policy applies to the DroidForge Claude Code plugin, developed by SUDARSHANCHAUDHARI / SudarshanTechLabs.

What DroidForge Does

DroidForge is a Claude Code plugin that automates repetitive Android development tasks — keystore creation, signing configuration, version bumping, Gradle version catalog management, new app scaffolding, and release checklists. It reads and writes local project files on your machine.

Data Collection

DroidForge does not collect, transmit, or store any user data. Specifically:

  • All file reading and generation happens locally on your machine
  • No data is sent to any external server by this plugin
  • Your developer conventions (name, company, package prefix, keystore password) are stored locally in .claude-plugin-config.json on your machine only — this file is automatically added to .gitignore by the setup command
  • Keystores generated by this plugin (.jks files) are created locally and never transmitted anywhere
  • No analytics, crash reporting, or telemetry is included in this plugin

Local Configuration File

When you run /droidforge:setup, the plugin creates a .claude-plugin-config.json file in your project directory. This file contains your developer name, company, package prefix, and keystore password. It is stored only on your local machine and is automatically excluded from git via .gitignore. It is never read, accessed, or transmitted by anyone other than Claude Code running locally on your machine.

Third-Party Services

DroidForge uses no third-party services. It interacts only with:

  • Your local filesystem (reading and writing project files)
  • The keytool command from your local Java JDK installation (for keystore generation, only when you explicitly confirm)
  • Your local git installation (for tagging releases, only when you explicitly confirm)
